# Pupu 验证地图

这里是验证 Pupu 用户行为的维护来源。验证前先读这页，再按功能文件走。

## 基线

- 云端在 `http://localhost:5199`，空数据启动，`doctor.mjs` 通过。
- 本机没设 `ACCESS_TOKEN`，请求不带凭据也放行，网页打开即登录。
- 一次只有一个验证实例，只驱动这次启动的实例。

## 驱动约定

- 优先用 aria-label、placeholder 和可见文字，少用坐标。
- 改动过数据后，用 `curl -s localhost:5199/api/state` 做第二视角确认。
- 下面的命令照抄，`$S`、`$E`、`$U` 的含义见 `SKILL.md`。

## 证明和跳过

- 记录功能编号和入口。
- 走不到的入口写清尝试过的命令和缺的前提，不算通过。

## 功能

- [项目](./projects.md)：建项目、整页列表切换、在项目里说话的入口。
- [聊天](./chat.md)：发消息、收回复、模型出错的提示。
- [私聊](./private-chat.md)：大家和私聊切换、别人打不开、审批和报告卡只给相关的人。要几个成员。
- [设置](./settings.md)：设备和电脑列表、配对码。
- [电脑配对](./desktop-pairing.md)：电脑 App 配对并上线。
- [手机连接](./ios-connect.md)：配对链接把手机连上，手机看到云端数据。
